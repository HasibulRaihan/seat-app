# SEAT — Social Engineering Awareness Training

A web application for training users to identify social engineering attacks.

## Tech Stack
- Frontend: React.js (Vercel)
- Backend: Node.js + Express (Render)
- Database: MongoDB Atlas

## Live URL
- Frontend: https://seat-app-neon.vercel.app
- Backend: https://seat-app-api.onrender.com

## Setup
1. Clone the repo
2. cd server && npm install
3. cd client && npm install
4. Add .env file with your MongoDB URL
5. npm start in both folders
